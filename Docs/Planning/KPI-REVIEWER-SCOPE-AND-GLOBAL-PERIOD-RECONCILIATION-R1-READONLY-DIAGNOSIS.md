| المتغيّر | القيمة الفعلية |

- **Idempotent**: قبل كل خطوة يُطابَق `(Id, OldPeriodKey)`؛ إن كان المفتاح = الهدف بالفعل ⇒ `AlreadyApplied` بلا كتابة.
- **الحماية**: إن وُجد سجلّ في الهدف بنفس `(ReportTemplateVersionId, SubmitterId, PeriodKey, IsDeleted=false)` ⇒ `CollisionSkipped` **ولا يُحذَف ولا يُستبدَل شيء**.
- **الحقول المكتوبة**: `PeriodKey` **حصرًا** (+ `UpdatedAtUtc` اختياريًّا). ممنوع لمس: `Status`، `CreatedAtUtc`، `SubmittedAtUtc`، `ClosedAtUtc`، `CurrentApproverId`، `SubmitterId`، `ReportTemplateVersionId`، `IsDeleted`.
- **التدقيق**: صفّ في `audit_logs` لكل سجلّ: `SubmissionId، OldPeriodKey، NewPeriodKey، ExecutedAtUtc، ExecutedBy، OperationName="GLOBAL-PERIOD-RECONCILIATION-W27-W29-R1"، Reason`.
- **Rollback**: عكس الترتيب (W28→W27 ثم W29→W28) + نسخة `pg_dump` احتياطية قبل التنفيذ.

**النتيجة المتوقّعة**: فاطمة تصبح W28 + W29 + W30؛ يختفي `2026-W27` كفترة تشغيلية؛ لا سجلّ جديد؛ لا Duplicate؛ لا تغيير حالة أو محتوى؛ التقارير اللاحقة والتقويم الحالي بلا أثر.
