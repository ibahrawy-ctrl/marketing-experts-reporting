## 2) ما الذي يفعله الجسر — ولا يفعله

الأداة: `Ops/MigrationHistoryBridge/bridge.sh` (نسخة الخادم `/root/mhbridge/bridge.sh`).

- **يفعل:** إدراج **صفَّين اسميَّين فقط** في `__EFMigrationsHistory` يُعلِمان EF أنّ هجرتَي
  النَسَب الموحّد مطبَّقتان مسبقًا بحكم وجود الجدولين فعليًّا.
- **لا يفعل:** لا يحذف صفًّا، لا يعدّل صفًّا قائمًا، لا يلمس أيّ جدول بيانات، لا يغيّر مخطَّطًا.
- **الوضع الافتراضيّ:** تشغيل جافّ (Dry Run). التنفيذ لا يقع إلّا بعَلَم صريح.
- **متكرّر الاستدعاء بلا أثر (Idempotent):** الإدراج مشروط بغياب الصفّ.
