## 5. إثبات التجميع بـ `ClientId` + `ProjectId` (لا بالنصّ)

المتطلّب الحاسم: التجميع **يجب** أن يكون بالمعرّفات لا بأسماء العملاء/المشاريع ولا بتحليل الاسم ولا بخريطة يدويّة.

الإثبات من الكود:

```tsx
const UNASSIGNED_CLIENT_KEY   = '__amr_unassigned_client__';
const UNASSIGNED_CLIENT_LABEL = 'عميل غير محدّد / بيانات تاريخية';

// مفتاح المجموعة = ClientId (أو مفتاح ثابت للحالة التاريخيّة بلا عميل)
const clientKey = entry.clientId ?? UNASSIGNED_CLIENT_KEY;

// المرساة = ProjectId
const baseAnchor = entry.projectId
  ? `amr-project-${entry.projectId}`
  : `amr-project-row-${index}`;
```

- لا يوجد في المسار أيّ `split`/`indexOf`/`match` على اسم مشروع أو اسم عميل لأغراض التجميع.
- الاسم النصّي يُستعمل **للعرض فقط** (`fullTitle = «اسم المشروع — اسم العميل»`).
- الحالة التاريخيّة (سجلّ بلا `ClientId`) لها مجموعة واحدة معنونة صراحةً، بلا خلط مع عملاء حقيقيّين.
