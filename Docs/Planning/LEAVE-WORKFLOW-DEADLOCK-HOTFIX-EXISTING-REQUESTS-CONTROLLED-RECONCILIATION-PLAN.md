## القسم 7 — Idempotency Plan (خطة عدم التكرار)

1. **مرجع الحالة قبل التنفيذ:** لقطة قراءة لكلّ RequestId مستهدف (Status/CurrentStep/Ledger count) — القيمة المرجعيّة الحاليّة: كلّها Ledger=0.
2. **حارس الطيّ:** لا يُطبَّق الإصلاح المحكوم إلّا على طلب حالته فعليًّا `TeamLeaderApproved/CurrentStep=Manager` وتصنيفه B (`op_mgr_above=0`)؛ أيّ حالة أخرى تُرفَض بلا أثر.
3. **حارس الخصم:** الخصم النهائيّ محميّ بفهرس/فحص (RelatedRequestId, Source=ApprovedLeave) ⇒ تكرار الاعتماد لا يُنتج Debit ثانيًا.
4. **إعادة التشغيل الآمنة:** إعادة تنفيذ الخطة على طلب سبق طيّه ⇒ حالته لم تعد Manager ⇒ يُتخطّى (لا تغيير، لا Ledger مكرّر).
5. **تحقّق بعديّ:** إعادة قياس Ledger count لكلّ RequestId (متوقَّع: 1 بعد اعتماد HR الطبيعيّ، لا أكثر) + عدم تغيّر أيّ طلب خارج القائمة.
