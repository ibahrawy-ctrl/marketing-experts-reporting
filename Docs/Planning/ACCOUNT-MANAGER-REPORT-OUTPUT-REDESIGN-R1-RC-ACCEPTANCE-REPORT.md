استُعلمت قاعدة `reporting_rc` مباشرةً (SELECT فقط، بلا أيّ تعديل/تسليم/اعتماد). النتائج:

### ما الذي تُثبته بيانات RC الحقيقية فعليًّا

- **البند M (قالب بلا Profile يُعرَض بالمصيّر العامّ) — مُثبَت ببيانات حقيقيّة:** توقيع الـProfile يشترط `deliverables_sent && decisions_required && client_relationship`، وفرع العنوان يشترط `decisions_required`؛ ومفاتيح W28 لا تحوي أيًّا منها (تحوي `decisions` لا `decisions_required`) ⇒ `resolvePresentationProfile` يُعيد `null` ⇒ **المصيّر العامّ**. أي: **صفر انحدار** على التقارير القائمة.
