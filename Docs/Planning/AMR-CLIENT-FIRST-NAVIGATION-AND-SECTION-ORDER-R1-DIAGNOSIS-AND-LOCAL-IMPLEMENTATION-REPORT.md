## 7) سلوك التفاعل

`openProjectAndNavigate(anchorId, clientKey)` = **مصدر تنقّل واحد** يستعمله زرّ التنقّل السريع **وخليّة اسم المشروع في الجدول** معًا (لا مسار منطقيّ ثانٍ):

1. فتح مجموعة العميل إن كانت مغلقة.
2. فتح بطاقة المشروع إن كانت مطويّة.
3. `setScrollRequest({id, seq})` ⟶ داخل `useEffect` **بعد اكتمال تحديث DOM**:
   - `scrollIntoView({ behavior: 'smooth', block: 'start' })`
   - `focus({ preventScroll: true })` على `h4` العنوان (`tabindex="-1"`)
   - إبراز مؤقّت `ring-2 ring-orange ring-offset-2` يُزال تلقائيًّا بعد **2200ms**
4. لا يُغلق أيّ مشروع آخر مفتوح، ولا يفتح مشروعًا آخر يحمل نفس الاسم.

**زرّ العودة:** `↑ العودة إلى قائمة العملاء والمشروعات` في نهاية كلّ بطاقة ⟶ تمرير إلى `#amr-quick-nav` بلا إعادة تحميل وبلا تغيير حالة.

**قياس زمنيّ فعليّ داخل الصفحة:** عند t=100ms و t=1000ms بعد الضغط ⟶ الصنف `ring-2 ring-orange ring-offset-2` موجود و`document.activeElement.id === 'amr-pcard-pr-a2-title'`؛ عند t=2600ms ⟶ الإبراز أُزيل. جسم البطاقة ينقلب `hidden … print:block` ⟶ `block … print:block`.

| 6 | مشروعه الثاني + رأس «العميل: نادي النموذج الرياضيّ» + مشروعه | ✅ |
| 7 | **نظرة عامة** (الملخص الأسبوعي + أبرز التحديات) ثمّ الملاحظات الإدارية | الأقسام العامّة **بعد** المشاريع ✅ |

**روابط العودة الستّة لا تظهر في الطباعة** — حاويتها تحمل `print:hidden` (المسبار الأوّليّ الذي أظهر `backLinksVisible: 6` كان يقيس `display` الخاصّ بالزرّ لا بالحاوية الأب؛ الـPDF يحسم أنّها مخفيّة). **لا يلزم أيّ تعديل إضافيّ.**

**قيد بيئيّ يجب الإفصاح عنه:** متصفّح المعاينة (Chromium بلا رأس) **لا يُحرِّك** `behavior:'smooth'` إطلاقًا — أُثبت بمسبار: `behavior:'auto'` ⟶ scrollY=1814، بينما `window.scrollTo({top:1200, behavior:'smooth'})` بعد 700ms ⟶ بلا حركة، و`prefers-reduced-motion` = false. هذا **قيد بيئة التقاط اللقطات لا عيب في المكوّن** (المنطق نفسه — تحديد العنصر الصحيح + نقل التركيز + الإبراز — تحقّق برمجيًّا). في لقطة رقم 5 عُوِّض ذلك بتمرير صريح.
