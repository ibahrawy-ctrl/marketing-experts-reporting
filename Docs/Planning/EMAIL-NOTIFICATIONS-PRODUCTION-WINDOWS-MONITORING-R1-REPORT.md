**التصنيف:** 🔴 **ثغرة مؤكَّدة (Gap)** — **لا تُصنَّف «بالتصميم»**.
**مستوى الخطورة:** **عالٍ** — يمسّ تنبيهات التأخّر والملخّصات الرقابيّة، وهي جوهر الغرض من القناة.
